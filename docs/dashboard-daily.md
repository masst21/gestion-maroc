# Widget quotidien / Mon Magasin
Ville par défaut : Agadir. Choix enregistré dans le navigateur (pas dans la base).
Horloge Africa/Casablanca, date hégirienne calculée et signalée comme estimée.
Prières : AlAdhan méthode 21, référence officielle https://www.habous.gov.ma/ ; les résultats calculés ne sont pas des horaires officiels.
Météo : MET Norway Locationforecast, licence CC BY 4.0, prévisions arrondies. La météo reste désactivée tant que le responsable n'a pas lu et accepté https://docs.api.met.no/doc/TermsOfService ; ensuite définir DASHBOARD_MET_TERMS_ACCEPTED=true côté serveur (Preview puis Production). Aucun secret nécessaire. Revalidation 6 h. Les données personnelles ne sont pas envoyées.
Le widget n'effectue aucune écriture dans PostgreSQL.
